# RARA Fast Trim

**Free Windows Video Trimmer & Frame Capture Tool**

RARA Fast Trim is a free Windows desktop application for quickly trimming videos using simple Start and End controls, without a complicated editing workflow.

## Features

- Open and preview video files
- Select exact Start and End positions
- Save trimmed MP4 videos
- Capture individual frames as PNG or JPG
- Simple, lightweight Windows desktop interface
- Free to use
