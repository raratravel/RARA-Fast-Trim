# RARA Fast Trim

**Free Windows Video Trimmer & Frame Capture Tool**

RARA Fast Trim is a free Windows desktop utility for selecting start and end points, trimming a video to an MP4 clip, and capturing individual video frames as PNG or JPG images.

## Application screenshot

![RARA Fast Trim application interface showing video preview, start/end controls and frame capture](screenshots/rara-fast-trim-interface.png)

## Features

- Open and preview a video.
- Set trim start and end positions.
- Save the selected segment as an MP4 video.
- Capture a video frame as a PNG or JPG image.
- Use a straightforward Windows desktop interface.
- Free to use.

## How to use

1. Open a video with **Open Video**.
2. Preview the video, then choose the desired **Start** and **End** positions.
3. Select **Save Trim** to export the segment as MP4.
4. To save a still image instead, select **Capture Frame (JPG / PNG)**.
